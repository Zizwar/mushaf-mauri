## المشكلة

التطبيق يدعم روايتَي ورش (6214 آية، عدّ مدني أخير) وحفص (6236 آية، عدّ كوفي). عند الضغط على آية في وضع ورش، كانت الدالة `warshToHafsAyahs()` ترسل رقم الآية مباشرةً إلى API تفسير KSU (الذي يستخدم ترقيم حفص)، مما ينتج عنه تفسير خاطئ في السور التي يختلف فيها الترقيم.

---

## الحل

إضافة خريطة استثناءات كاملة `WARSH_EXCEPTIONS` في `src/utils/tafsir.ts` تغطي جميع السور ذات الاختلاف في العدّ.

### أنواع الاختلاف

| النوع | الوصف | مثال |
|-------|-------|-------|
| **دمج** (merge) | ورش يدمج آيتين حفص في آية واحدة | W1 = H[1,2] |
| **تقسيم** (split) | ورش يقسم آية حفص إلى آيتين | W15+W16 = H15 |
| **فواتح** | ورش يدمج الحروف المقطعة مع الآية التالية | "الم" + "ذلك الكتاب" = آية واحدة |

---

## هيكل الكود

```typescript
const WARSH_EXCEPTIONS: Record<number, ...> = { ... }

export function warshToHafsAyahs(sura: number, warshAya: number): number[]
```

### أنواع الاستثناءات في الكود

- **`manual`**: خريطة يدوية كاملة (الفاتحة فقط)
- **`offset`**: دمج فاتحة عند الآية 1 بإزاحة ثابتة +1 لكل ما بعدها
- **`advanced`**: `explicit_map` لنقاط الدمج/التقسيم + `ranges` لنطاقات الإزاحة المتغيرة
